# Venda em Dia

Primeira versão manual do assistente de vendas. IA e WhatsApp ainda não estão conectados.

## Abrir no computador

1. Clique em Code > Download ZIP neste repositório.
2. Extraia o ZIP.
3. Abra index.html no navegador.
4. Clique em Abrir exemplo fictício para testar.

## Recursos

- Cadastro de clientes e conversa colada manualmente.
- Busca e filtros por situação.
- Próxima ação, observações, data e motivo de retomada.
- Resposta editável com botão para copiar.
- Roteiro de áudio em texto para gravação manual.
- Cadastro das informações das ofertas.

## Limites desta versão

Os dados ficam no armazenamento local do navegador, sem login, backup ou sincronização. Limpar os dados do navegador pode apagar os registros. Use dados fictícios nesta fase. Não há análise automática, geração de voz ou envio de mensagens. Nenhuma chave de API é necessária. Nunca coloque conversas reais ou credenciais neste repositório público.
